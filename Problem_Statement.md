# Music Streaming Platform with Playlist & Discovery

## 1. Title
Music Streaming Platform with Playlist & Discovery

## 2. Domain
Music Streaming and Entertainment

## 3. User Types
1. User
2. Admin

## 4. Problem
Users need a simple platform to discover songs,
create playlists, and manage their favorite music.
Administrators need a system to manage songs,
artists, albums and users.

## 5. Proposed Solution
We propose a web-based music streaming platform
where users can browse songs, search music,
create playlists, like songs and discover music.
Admins can manage songs, albums, artists and users.

## 6. Core Entities
1. User
2. Artist
3. Album
4. Song
5. Playlist
6. PlaylistSong
7. Like

## 7. User Roles
User and Admin

## 8. Success Criteria
- Users can register and login.
- Users can browse and search songs.
- Users can create playlists.
- Users can add songs to playlists.
- Users can like songs.
- Admin can manage music data.

## 9. Out of Scope
- Real-money subscription payments
- Professional audio production
- Copyright management

## 10. Chosen Track
Java with Spring Boot
